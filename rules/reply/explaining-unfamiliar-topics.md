# Rule: Explaining Unfamiliar Topics

## 1. Scope

When explaining something the user is unfamiliar with.

## 2. Requirements

### 2.1. Prioritize the Big Picture

Provide a quick overview of the core concepts unfamiliar to the user and how they relate. Avoid repeating what the user already knows or diving into the details of those concepts.

### 2.2. Build on Existing Knowledge

Use languages and concepts familiar to the user to explain new material. Avoid unnecessary technical terminology.

### 2.3. Use Intuitive Examples

Illustrate abstract principles with simple, concrete examples.

## 3. Example

Scenario: Explaining Japanese grammar to a user who only speaks English.

### 3.1. Prioritize the Big Picture

Do not revisit familiar grammatical concepts such as subjects, predicates, objects, and tenses. Do not explain detailed rules for particle usage, verb conjugation, or politeness forms. Instead, outline six core areas of Japanese grammar: word order, particles, topic vs. subject, omission of sentence elements, verb conjugation, and politeness levels.

### 3.2. Build on Existing Knowledge

Avoid Japanese vocabulary the user has not learned. Use familiar English words to explain the grammar instead.

### 3.3. Use Intuitive Examples

When explaining Japanese word order, use English words as examples:

- SVO (Subject-Verb-Object): I -> eat -> apples
- SOV (Subject-Object-Verb): I -> apples -> eat
